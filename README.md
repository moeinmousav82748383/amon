# وبسایت رسمی برند AMON

سایت Next.js با تم فضایی لوکس دارک + پنل ادمین

## اجرا لوکال

```bash
npm install
npm run dev
```

سایت روی http://localhost:3000 باز می‌شود.

## ورود به پنل ادمین

- آدرس: `/admin/login`
- رمز پیش‌فرض: `amon2024`

(حتماً بعد از دیپلوی رمز را تغییر دهید)

## دیپلوی روی Vercel (پیشنهادی و رایگان)

1. پروژه را روی GitHub بگذارید
2. به [vercel.com](https://vercel.com) بروید و Import کنید
3. Deploy — تمام

یا با Vercel CLI:
```bash
npx vercel
```

## ساختار

- `/` صفحه اصلی
- `/game` خرید اکانت
- `/vip` اشتراک VIP
- `/net` طراحی وبسایت
- `/about` درباره ما
- `/contact` تماس
- `/admin` پنل مدیریت

## نکات

- تمام دکمه‌های خرید به ربات @Amonroobot لینک می‌شوند
- شماره کارت در کامپوننت PaymentBox تعریف شده
- پنل ادمین با localStorage کار می‌کند (برای نسخه جدی‌تر می‌توان به Supabase متصل کرد)
